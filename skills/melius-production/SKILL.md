# Melius production adapter

Require all four current creative approvals. Read the actual supplied Melius docs in the workspace references/melius directory and campaign documentation. Record source, version/date and confirmed capabilities. This repository ships with no Melius API or provider capability claims.

Without docs, produce universal plain-language briefs. Never invent endpoints, flags, prompt tokens, duration/resolution limits, seeds, audio support, reference slots or credit prices. Do not substitute another production engine. The compiler deliberately emits prose even when future docs are supplied; document-specific manual adaptations must cite their source and preserve the universal brief.

Use the agency shot-plan.json and production templates. Each shot repeats its objective, visual, subject, environment, composition, camera, movement, light, colour, texture, action, product details, continuity, start/end frames, duration, sound intent, constraints and reference roles.

Create the master brief and generation plan with the agency tool after approvals. Check timing totals and actual product/identity continuity. Plan variants and maximum attempts, high-risk tests, validation order and fallback. Actual costs remain UNKNOWN until checked in Melius. A plan is not permission to spend.

The user generates in Melius and places outputs in 08_generations. Route those to the agency review workflow. Never launch a generation as a side effect of briefing or testing.
